# Scrim POVs

A web-app to watch different YouTube videos alongside each other.

## Features

- video highlight/focus to make them almost fullscreen
- nine videos at the same time
- synced controls to control all videos together
- settings to sync the videos across different browsers

## Tech Stack

React, Tailwind and Next.js
